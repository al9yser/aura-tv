# أورا TV — Aura TV

مشغّل IPTV لهواتف أندرويد والتلفاز. **مشغّل فقط: لا يتضمن أي قنوات.** تضيف أنت قائمة M3U أو حساب Xtream من مزوّد تملك حق استخدامه.

الألوان: موف (بنفسجي) + رمادي + ذهبي. الواجهة عربية RTL مع الإنجليزية.

## الحصول على ملف APK (الطريقة الأسهل — بدون تثبيت أي شيء)

1. أنشئ مستودعاً جديداً في GitHub وارفع محتويات هذا المجلد كما هي (بما فيه مجلد `.github`).
2. افتح تبويب **Actions** ← **Build APK** ← **Run workflow** (يعمل تلقائياً أيضاً عند كل push).
3. بعد نحو 5–10 دقائق افتح التشغيل الناجح ونزّل **aura-tv-apk** من قسم Artifacts.
4. انقل `aura-tv.apk` للهاتف أو التلفاز وثبّته (فعّل «التثبيت من مصادر غير معروفة»).

الـAPK الناتج موقّع بمفتاح التطوير (debug) ويُثبَّت مباشرة. للنشر في Google Play تحتاج توقيع Release بمفتاحك الخاص.

### البناء على جهازك بدلاً من GitHub
يلزم Node 20 وJDK 17 وAndroid SDK:
```
npm install && npm test && node scripts/prepare-web.mjs
npx cap add android && python3 scripts/patch_android.py && npx cap sync android
cd android && ./gradlew assembleDebug
```
الملف: `android/app/build/outputs/apk/debug/app-debug.apk`

## المزايا
- **المصادر:** رابط M3U، ملف/نص M3U، حساب Xtream Codes (مباشر + أفلام + مسلسلات بحلقاتها). عدة قوائم وتبديل بينها وتحديث بضغطة.
- **فلاتر وبحث:** تبويبات (مباشر/أفلام/مسلسلات/المفضلة/الأخيرة)، تصنيفات بالعدد، جودة (4K/FHD/HD/SD)، ترتيب أ-ي، وبحث فوري يتجاهل التشكيل وفروق الألف والتاء المربوطة (جزيرة = جزيره).
- **أداء:** يتعامل مع قوائم بعشرات الآلاف (عرض تدريجي + تخزين IndexedDB، فتح فوري من الكاش).
- **المشغّل:** يختار المحرّك المناسب تلقائياً (HLS / MPEG-TS / مباشر) ويجرّب البدائل عند الفشل؛ إعادة اتصال تلقائية بتأخير متدرّج عند انقطاع البث؛ رسالة خطأ واضحة مع إعادة/التالي/رجوع؛ تغيير القناة، المفضلة، أبعاد الصورة، تقديم للأفلام، إبقاء الشاشة مضاءة.
- **سهولة الوصول:** أهداف لمس ≥ 44px، تباين عالٍ، تسميات للقارئات الشاشية، تنقّل كامل بالريموت (الأسهم/OK/رجوع/قنوات +/−)، واجهة أكبر للتلفاز، زر رجوع أندرويد يغلق الطبقة الحالية.
- **الخصوصية:** كل شيء محلي على الجهاز. لا حسابات ولا تتبّع.

## ما جرى اختباره فعلاً
- 8 اختبارات وحدة (المحلّل، Xtream، اختيار المحرّك) — تعمل أيضاً في CI قبل البناء.
- 48 فحصاً في متصفح Chromium حقيقي ضد خادم IPTV وهمي (`node tests/e2e.cjs`): الإضافة والأخطاء، الفلاتر والبحث العربي، المفضلة، تشغيل فيديو حقيقي، التنقل بين القنوات، رابط ميت، Xtream (خطأ كلمة المرور/نجاح/مسلسلات)، الاستمرارية بعد إعادة التحميل، التنقل بلوحة المفاتيح. النتيجة: 48/48 بلا أخطاء JavaScript.

## حدود يجب معرفتها (بصراحة)
- **لم يُبنَ ملف APK نفسه في بيئة التطوير** (لا يوجد Android SDK ولا تحميل له هناك). الواجهة والمنطق مختبران بالمتصفح؛ أما التجميع على أندرويد فيحدث في GitHub Actions. أول بناء قد يحتاج تعديلاً بسيطاً إن اختلف إصدار أداة؛ أرسل لي سجل الخطأ وأصلحه.
- التطبيق مبني بتقنية الويب داخل أندرويد (Capacitor). بعض خوادم البث لا تسمح بالقراءة من تطبيقات الويب (قيود CORS). تفعيل `CapacitorHttp` يتجاوز ذلك في أغلب الحالات، لكن إن وُجد خادم لا يعمل معك فالحل الأمتن هو نسخة أصلية بـKotlin وExoPlayer (أستطيع بناؤها كخطوة تالية).
- الدليل الإلكتروني للبرامج (EPG) ومزامنة السجل بين الأجهزة غير مضمّنين في الإصدار الأول.
- الصور الحقيقية للقنوات تُحمَّل من شعارات قائمتك؛ تظهر الأحرف الأولى عند غيابها.
- بيانات حساب Xtream تُحفظ نصاً داخل تخزين التطبيق المحلي على الجهاز.
